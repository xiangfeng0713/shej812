# 设计中台 2.0

本分支基于已确认的设计中台 1.5 建立，用于按照《设计中台搭建规范》持续调整界面与布局。

## 当前范围

- 主色统一为 `#2962FF`，并接入规范中的辅助色、功能色和中性色。
- 中文字体使用微软雅黑，英文字体使用 Arial。
- 页面最小字号统一为 13px。
- 标题栏高度统一为 60px。
- 大模块间距统一为 20px，小模块间距统一为 8px。
- 按钮圆角统一为 6px，输入框和卡片圆角统一为 8px。
- 左侧导航在“需求提交”下新增“任务看板”。
- 任务看板展示当前账号的待办、已处理和已提交任务，并可进入任务当前节点。

## 保护范围

- 需求流程节点和流转逻辑不变。
- 既有流程字段不变。
- 设计中台 1.5 的代码目录、分支和版本标签不变。
- 2.0 使用独立业务数据快照进行预览和测试。
