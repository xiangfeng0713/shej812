# AI视觉·无界舱｜流程节点 1.0 基线

确认日期：2026-08-14

以下流程节点及核心规则已确认，后续默认不改动，除非有明确调整指令。

1. 填写需求：部门、优先级颜色区分；任务类型含图片、视频、图片拍摄；日期与时间分开选择。
2. 部门负责人审批：审批人由需求中的内部审批人决定；优先级颜色区分。
3. 设计需求分配：设计负责人、协作设计师、设计方向、期望交付日期、优先级确认；持续展示需求方文案链接。
4. 需求校对：校对文案、素材参考、交付时间；退回需求方补充后，再次提交直接回到本节点。
5. 需求交付：交付人自动同步设计负责人；共享盘交付路径与最终交付日期必填。
6. 初稿审核：由向峰审批负责；共享盘路径只读可复制；退回直接回到需求交付，重新交付后进入复审版本。
7. 需求方验收 / 评分：验收人自动同步提交人；共享盘路径只读可复制；预留 AI 图片评分入口；人工复核等级 A=95、B=85、C=70、D=50；退回直接回到需求交付。
8. 验收完结：验收通过后自动闭环；保留验收人、人工评分、最终交付日期、完结时间与可复制共享盘路径。
